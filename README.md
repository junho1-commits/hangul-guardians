# 한글 지킴이
한글날에 세종대왕, 주시경 선생님과 함께 우리말을 배우는 놀이입니다.

## 실행
실행하기.bat을 두 번 누르면 첫 화면(http://localhost:3000/)이 열립니다. 실행 창을 열어 두세요.
이미 실행 중이면 실행 창에서 Ctrl+C로 끝낸 뒤 다시 실행하세요.

## 세 가지 놀이
- 학습 모드 — 배우기 (/learn): 맞춤법, 순우리말, 다듬은 말, 띄어쓰기 중 골라 배웁니다. 시간 제한 없이 플래시 카드 앞면을 보고 생각한 뒤 뒤집어 정답과 풀이를 확인합니다. 도움말, 이전·다음 이동, 다시 볼 카드 별표와 별표 카드만 복습하기를 제공합니다. 모든 내용을 고르면 48장, 한 갈래를 고르면 12장입니다.
- 개인 모드 — 혼자 하기 (/solo): 고른 내용에서 12문제를 섞어 풉니다. 한 문제에 30초이며, 답을 고르거나 시간이 끝나면 바른 답과 풀이를 봅니다. 마지막에 맞힌 수와 틀린 문제, 내가 고른 답을 확인합니다.
- 단체 모드 — 함께 하기: 교사 /host에서는 배우기·혼자 하기·함께 하기·방 개설을 선택하며, 방 개설을 눌러야 대기실이 생성됩니다. 학생 /play에서는 배우기·혼자 하기·함께 하기를 선택하고 함께 하기에서 6자리 번호와 이름으로 들어옵니다. 같은 무선 인터넷에 연결해야 합니다. 최대 60명이 함께 맞춤법 → 순우리말·다듬은 말 → 띄어쓰기를 풉니다.

## 함께 하기
선생님 화면의 교실 접속 주소를 고르고, 학생은 그림 주소를 찍거나 주소를 입력합니다. localhost 주소는 다른 학생 기기에서 사용할 수 없습니다.
한글 지킴이 출발을 누르면 시작 이야기 뒤에 문제가 나옵니다. 답을 맞히면 먹물이 줄고 두 지킴이의 힘이 모입니다. 힘이 가득 차면 함께 쓰는 큰 힘이 나옵니다.
잠시 멈춤, 도움말 보기, 답 받기 끝내기, 다음 문제로 수업을 이끕니다. 개인 순위와 틀린 학생 이름을 공개하지 않습니다.
그림 주소로 들어오지 못하면 학교 무선 인터넷의 기기 간 연결 차단과 Windows 방화벽 설정을 확인하세요.

## 자료와 말
문제는 questions.js에 있으며 총 48개입니다. 외래어의 뜻을 묻는 문제의 학습 대상 낱말은 유지했습니다.
화면의 힌트는 도움말, 인트로는 시작 이야기, 결계는 보호막, 합동 필살기는 함께 쓰는 큰 힘으로 바꿨습니다.
훈민정음과 인물 이름처럼 배워야 할 고유 이름은 유지합니다. 두 인물이 함께 등장하는 것은 상상 이야기입니다.
배우기와 혼자 하기는 답과 풀이를 읽을 수 있는 학습 자료를 사용합니다. 함께 하기에서는 출제 중 답을 실시간으로 보내지 않습니다.
이름과 단체 답은 실행 중인 컴퓨터의 메모리에만 보관하며 종료하면 사라집니다. 개인 결과는 해당 화면에만 표시하며 새로 고침하면 초기화됩니다.

## 음성과 확인
음성 13개를 모두 Typecast로 통일했습니다. 이야기꾼은 지영, 세종대왕은 성호, 주시경 선생님은 지훈, 먹물 도깨비는 찬구입니다. 바뀐 대사 8개를 새로 제작하고 나머지 5개는 기존 Typecast 음성을 유지했습니다. 기존 음성 원본은 public/audio/original에 보관했습니다. 실행 중에는 저장된 음성을 재생하며 인터넷이나 음성 제작 열쇠가 필요하지 않습니다.
npm test: 단체 놀이 규칙 8개 검사.
node tests/modes-smoke.cjs: 세 가지 놀이, 도움말, 시간 종료, 결과, 다시 풀기, 단체 진행, 휴대기기 화면 검사.
npm run voices: Typecast로 대사를 다시 만들 때 사용하며 TYPECAST_API_KEY와 인터넷이 필요하고 사용량을 소비합니다.

배우기·혼자 하기는 저장된 public/practice-bank.js를 읽으므로 이전 실행 서버에서도 작동합니다. questions.js를 수정하면 node scripts/export-practice.cjs로 갱신하세요. 실행하기.bat과 npm start는 시작할 때 자동 갱신합니다.

## 온라인 배포
Render의 Node 웹 서비스로 배포할 수 있도록 render.yaml을 포함했습니다. GitHub 저장소를 연결해 Blueprint를 만들면 서버와 단체 모드가 함께 실행됩니다. 공개 접속 주소는 Render의 RENDER_EXTERNAL_URL을 자동으로 사용하며, 다른 서비스에서는 PUBLIC_URL을 설정합니다. 대기실 조작에는 기존 교사용 인증 토큰이 필요합니다.
무료 Render 서버는 일정 시간 사용하지 않으면 잠들 수 있으므로 수업 전에 접속해 준비하세요. 서버 재시작 시 진행 중인 대기실은 초기화됩니다.
